# plantae lukavec

This project is a wordpress template. Final website that uses this wordpress template leverages woocommerce. This website is a website that sells beautiful plants. Usual audience is people between 28-70 years old. This website is in czech only so foreign visitors are not expected. Write messages in czech for the content of the website.

Main font is "Montserrat" for content and for titles it is "Playfair Display". The font is automatically set with css no need to specify it manually. Main color is #f34f3f and secondary is #1a52007d. For EVERY styling use tailwindcss classes.
